# Contributing to FleetChain

Contributions are welcome! Whether it's fixing a bug, improving the documentation, suggesting an idea, or implementing a new feature, every contribution is appreciated.

1. Fork the repository.
2. Clone your fork and create a branch for your changes.
3. Run the checks locally:
   ```bash
   cargo fmt --all -- --check
   cargo test
   ```
4. Commit your changes and open a pull request against `main`.

## Pull Requests

- Keep changes focused and explain what problem they solve.
- Include or update tests when changing functionality.
- Make sure existing tests pass before submitting.
- Update documentation when appropriate.

## Reporting Issues

Found a bug or have an idea? Feel free to open an issue. Include enough context to reproduce bugs or understand your proposal.

Thanks for helping make FleetChain better!
